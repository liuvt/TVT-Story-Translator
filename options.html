Cài đặt TVT Story Translator

API • Phong cách • Từ điển truyện • TTS

Các quy tắc bên dưới được gửi cùng mỗi lần xử lý. Extension không tự đọc bộ nhớ ChatGPT của bạn.

1. OpenAI API

Cần khóa API từ OpenAI Platform. Gói ChatGPT Plus/Pro không bao gồm chi phí gọi API.

Không tích nếu dùng máy chung. Khóa lưu trên máy trong Chrome Extension Storage không được mã hóa riêng; không chia sẻ ZIP kèm API key.

2. Bộ quy tắc phong cách

Chọn từng preset để xem hoặc chỉnh trực tiếp lời nhắc sẽ gửi đến AI. Tất cả đều yêu cầu giữ đầy đủ nội dung nguồn.

3. Từ điển tên riêng / chống lỗi ASR

Mỗi dòng có dạng Sai => Đúng. Chỉ bật khi đúng tác phẩm (ví dụ truyện Cao Dương). Bạn có thể chỉnh, xóa hoặc thêm tên riêng.
